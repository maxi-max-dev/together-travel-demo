# 一起去玩 · 公开流程演练

[打开 Demo](https://maxi-max-dev.github.io/together-travel-demo/) · [功能与体验说明](https://maxi-max-dev.github.io/together-travel-demo/guide.html)

先聊需求，再核对条件；各自出发，一起确认方案，持续跟进变化。支持1–6位成人、有限代办，以及部分已模拟付款后的调整。

这个仓库只发布浏览器演练。对话使用有限规则；机酒报价、订单及付款均为模拟。数据保存在当前浏览器，不跨设备同步，关页停止跟进。无API密钥、真实成员数据或后端服务。

本机开发版接百炼与FlyAI真实候选，完整含费价和房型库存仍待核验。开发仓库由团队私密协作，和本公开演示分开发布。
