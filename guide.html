GO, TOGETHER · 公开演示 v9

各自说清期待，
把一趟旅行一起安排好。

面向1–6位成人的旅行委托。可以各自从不同城市出发，也可以由一个人先整理大家的条件。每个人分别确认预算、日期、航班限制和代办范围。

先从这里体验

  1. 在首页说几句需求。演示会整理草稿、追问缺项，也能回答预算等常见问题。
  2. 展开条件核对，确认自己的城市、日期、预算与限制；切换到朋友角色，分别确认。
  3. 比较共同方案，约定跟进目标和截止时间。
  4. 在“委托跟进”演练降价、缺价或班次变化，查看系统如何重新安排。
  5. 体验模拟付款。已有付款保留，受影响的项目需要重新确认，不能默认免费退订。
一个人出发替两人安排三人部分已订

这个公开链接能做什么

这是免登录的静态流程演练。对话使用有限规则整理，机酒行情、订单、付款均为模拟；数据只保存在当前浏览器，可切换虚构成员角色。每位访问者的数据互相独立，不能跨设备共同编辑。页面关闭后停止模拟跟进。当前只支持文字输入，截图和语音尚未接入。

服务器内测已接入什么

百炼整理自然语言需求，FlyAI搜索真实航班和酒店候选，接入多人共同方案、定时复查和条件变更后的重新安排。Max 服务器测试版支持通过邀请跨设备独立参与；完整含费价、具体房型总价与足量库存尚未补齐，因此真实数据模式仍停在“待核价”。下单始终模拟。

公开 Pages 本身没有 API 密钥；真实对话和多人协作从服务器内测入口使用。密钥只放在服务端。

每个人一个对话，共用一张旅行桌

桌面端左侧是自己的对话，右侧是共同进度；手机端在“我的对话”和“共同旅行”之间切换。个人原话不会给同行者查看，确认后的条件才共享。服务器保存本次旅行的对话，离开后回来可以接着聊；尚未实现跨旅行的长期记忆。

“想去 / 一定要去 / 不想去”会进入条件。同名地点出现必去与不去的冲突时，要先协商；当前不是完整的地点别名或营业时间校验器。

双人独立视角多人异步视角服务器内测

服务器版用 Max 的专属测试入口创建旅行，再给每位朋友发送独立邀请。每个人保留自己的浏览器身份；暂不支持丢失浏览器数据后的凭据找回。

一起讨论时最值得看

  • 能不能用几句话讲清楚，而不用上来就填长表？
  • 每个人预算、起降限制不同，方案有没有同时照顾到？
  • 一个人改了时间，其他人已确认或已付款的项目是否被正确保留？
  • 跟进到截止时间或信息不足时，下一步是否明确？
